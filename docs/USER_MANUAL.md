### Quick Start:
1. Run `setup_environment.bat` once to configure requirements and create desktop shortcut.
2. Run `start_tally.bat` to launch the application on http://127.0.0.1:5000.
3. Access Company Menu via Alt+K to create or select companies.
4. Press F4 to F9 to enter vouchers.
5. Press Alt+Y to create database backups.
